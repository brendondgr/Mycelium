# Planner Skill

Use this skill to produce clear implementation plans, migration plans, and
sequenced work breakdowns before coding.

## Core Rules

- Keep plans actionable and scoped to the repository in front of you.
- State assumptions explicitly when the answer is not fully known.
- Call out gaps, dependencies, and risks instead of hiding them in prose.
- Include concrete file, folder, command, or artifact references wherever
  possible.

## Output Shape

- Brief context or objective.
- Open questions or assumptions.
- Ordered phases or steps.
- Deliverables and validation for each phase.
- Git workflow guidance only when the user wants commit, push, or PR details.

## Good Plan Content

- What will change.
- Where it will change.
- How to verify it.
- What to defer.
