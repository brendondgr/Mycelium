# EXP-2026-09-005 — Issues

1. **A smoke run came first.** Before the protocol was written, an 8-person
   world (36 papers) was run end to end to prove the harness worked
   (`/app/data/sandbox/smoke.json`, not committed). It showed method terms
   carrying qualifiers ("specialized implementation of gradient boosting") and
   generic descriptions listed as methods, which is what arm B's revision
   targets. Its numbers are not results and are not reported.
2. **Dirty tree at scaffold time.** The harness was committed (d69e69f) before
   arm A ran; this folder, the protocol, and arm B's prompt revision were
   uncommitted while arm A ran. Arm A ran the committed `w1` prompt: the arm-B
   edit to `apps/knowledge/works.py` was written to disk after arm A's process
   had imported the module.
3. **The model wrote what it later read.** Abstracts are generated by the same
   local model (`default-model`, upstream `gemma4-26B-mtp`) that extracts the
   facets. Extraction on this corpus may be easier than on real abstracts;
   the numbers bound the pipeline's behaviour on clean, cooperative text, not
   its accuracy on the literature.
4. **The corpus is not committed.** The generated abstracts live at
   `/app/data/sandbox/collab-20260918-240.json` (ignored by git); its path and
   hash are in `data/POINTERS.md`. Regenerating it calls the model again and
   will not reproduce the same text.
5. **Signature matching is lexical.** Whether a method term "names" a planted
   method is decided by fixed fragments (`sandbox.collab.world.METHODS[*].
   signature`). A correct paraphrase with none of the fragments ("a recursive
   state estimator" for a Kalman filter) counts as a miss for `method_recall`
   and is invisible to the split and merge counts.
6. **Tokens were not counted.** The harness counts model calls and seconds,
   not tokens; the manifest records `null` rather than an estimate.
7. **The sweep leaves the sandbox at its last threshold.** `sweep` rebuilds
   every concept and edge; the saved re-score (`data/exp005-arm-b-rescored.json`)
   was made after re-linking at 0.92. Its exit code was 1 only because a
   score-only run has no second pass to report.
