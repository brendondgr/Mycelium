# Decision entry template

Copy into `DECISIONS.md`. Append only; a superseded decision gets a new entry
that names the one it replaces, never a silent edit.

```markdown
## D-00N — <the decision, as a statement>

**Date:** YYYY-MM-DD
**Context:** What forced the choice. What was true at the time.
**Options:** Each one considered, with the case for it — including the one
chosen. A list with one real option is a justification, not a decision record.
**Decision:** What was chosen.
**Consequences:** What this costs, what it rules out, and what a reviewer will
ask because of it.
**Revisit when:** The condition that should reopen this.
```
