# Autonomous research, hypothesis-generation and multi-agent scientific-discovery systems (compared to Mycelium)

Scope note: compiled 2026-11-08. GitHub star counts, licences and last-push dates were read directly from the GitHub REST API (`gh api repos/<owner>/<repo>`) on 2026-11-08 and are cited to the repo URL. "Unverified" marks anything I could not confirm from a primary page. Search snippets from aggregators (alphaxiv, emergentmind, moonlight AI reviews) were used only where flagged.

## 1. Catalogue: paper, group, venue/track, arXiv, repo, licence, stars, maintenance

### Takeaway
The field splits into (a) end-to-end "AI scientist" pipelines for ML research (AI Scientist v1/v2, Agent Laboratory, AI-Researcher, CycleResearcher, Dolphin, DeepScientist, MLR-Copilot, TinyScientist), (b) literature-grounded ideation/hypothesis systems (SciMON, ResearchAgent, Chain of Ideas, Scideator, IRIS, MOOSE-Chem, SciAgents, AI co-scientist), (c) domain lab agents with tools (ChemCrow, Coscientist, Biomni, Virtual Lab, Robin, Kosmos, data-to-paper), and (d) benchmarks. Only three are genuine ACL-family system-demo papers (IRIS ACL 2025 demo, TinyScientist EMNLP 2025 demo; ResearStudio EMNLP 2025 demo, unverified details); most of the influential work is main-track ICLR/NeurIPS/ACL/NAACL/EMNLP-Findings or Nature-family journals.

## 2. Architecture: loop vs pipeline, tools, memory, single vs multi-agent, human-in-the-loop

### Takeaway
Almost every "agentic" science system is actually a staged pipeline (ideate → plan → implement → run → write → review) where agency lives inside bounded stages (code-debug loops, tree search over experiments, tournaments over ideas). The real architectural variety is in (i) the search structure over ideas/experiments (tree search, MCTS, Elo tournament, evolutionary, Bayesian-optimisation-style), (ii) shared persistent memory (world model, findings memory, preprint server), and (iii) where humans intervene.

### Cited Findings
- **AI Scientist v1**: idea generation → experiment from a human-written code template → paper write-up → automated LLM reviewer; v2 drops the templates and uses a parallelised **agentic tree search managed by an experiment-manager agent** through four stages (explore hypotheses, tune hyperparameters, ablations) — [HF paper page](https://huggingface.co/papers/2504.08066); stages summarised by [Vector Institute](https://vectorinstitute.ai/?p=26786).
- **Agent Laboratory**: takes a **human-provided idea** and runs three phases — literature review, experimentation, report writing — producing a report and code repo; supports a "co-pilot" mode with human feedback at each stage — [ACL Anthology](https://aclanthology.org/2025.findings-emnlp.320).
- **AgentRxiv**: a shared preprint server where separate agent "labs" upload and retrieve reports to build on each other's work — i.e. memory as a shared document store — [arXiv](https://arxiv.org/pdf/2503.18102).
- **ResearchAgent**: starts from a core paper, expands via an **academic citation graph** and an **entity-centric knowledge store** mined across papers, then iteratively refines problem/method/experiment design with **multiple LLM reviewing agents** whose criteria are induced from human judgments — [arXiv](https://arxiv.org/abs/2404.07738).
- **SciMON**: retrieves "inspirations" from semantic-similarity graphs, a **knowledge graph** and **citation networks**, then iteratively compares generated ideas against prior papers and rewrites for novelty — [arXiv](https://arxiv.org/abs/2305.14259v5).
- **Chain of Ideas**: organises retrieved papers into a chronological chain reflecting how a field developed; evaluated with an Elo-style "Idea Arena" — [ACL Anthology](https://aclanthology.org/2025.findings-emnlp.477).
- **Scideator**: extracts **facets** (purpose, mechanism, evaluation) from user-chosen and analogous papers; three RAG modules — Analogous Paper Facet Finder, Faceted Idea Generator, Idea Novelty Checker (an earlier version also an Idea Novelty Iterator); human recombines facets — [arXiv](https://arxiv.org/abs/2409.14634v5).
- **IRIS**: input a research goal, output a brief (title, method, experiment plan); **MCTS** to scale test-time compute with alternating exploration/exploitation, fine-grained reviewer feedback, query-based literature synthesis; user can steer or let MCTS run — [ACL Anthology](https://aclanthology.org/2025.acl-demo.57).
- **MOOSE-Chem**: decomposes hypothesis = background + inspirations; three subtasks (inspiration retrieval, hypothesis composition, ranking); evolutionary generation, LLM-score ranking — [ICLR proceedings](https://proceedings.iclr.cc/paper_files/paper/2025/hash/51fd9a7d1706023cb9f8210cc6ac357c-Abstract-Conference.html).
- **SciAgents**: large ontological **knowledge graph** + LLMs with retrieval tools + multi-agent system (automated version on AG2/AutoGen); paths sampled through the graph seed hypotheses that agents expand and critique; needs OpenAI and Semantic Scholar keys — [SourcePulse](https://www.sourcepulse.org/projects/2165146), [awesome.ecosyste.ms](https://awesome.ecosyste.ms/projects/github.com%2Flamm-mit%2FSciAgentsDiscovery).
- **AI co-scientist**: Gemini multi-agent — Generation, Reflection, Ranking (Elo tournament via pairwise comparisons and simulated debates), Evolution, Proximity (clustering), Meta-review — under a Supervisor that schedules agents in parallel; "most of the system's computation goes to verifying hypotheses against literature and data" — [DeepMind blog](https://deepmind.google/blog/co-scientist-a-multi-agent-ai-partner-to-accelerate-research/).
- **Virtual Lab**: LLM **PI agent** + specialist scientist agents + **Scientific Critic** agent; "team meetings" (all agents on an agenda: responses, critique, summary) and "individual meetings" (human with one agent); parallel meetings whose summaries are merged; ~3 rounds per meeting; GPT-4o; built an ESM + AlphaFold-Multimer + Rosetta pipeline — [Freethink](https://www.freethink.com/artificial-intelligence/virtual-lab-interdisciplinary-research), [Stanford lecture slides](https://web.stanford.edu/class/biods271/assets/lectures/L5.pdf), [zou-group/virtual-lab](https://github.com/zou-group/virtual-lab).
- **Kosmos**: a **structured world model** shared by a data-analysis agent and a literature-search agent; each cycle runs up to ~10 parallel tasks, writes summaries back to the world model, then queries it to propose the next tasks; >200 rollouts, ~42,000 lines of code, ~1,500 papers per run (up to 12 h); every report claim is linked to the analysis or source it came from — [arXiv](https://arxiv.org/abs/2511.02824), [Edison](https://edisonscientific.com/articles/announcing-kosmos).
- **Robin**: orchestrates FutureHouse literature agents (Crow, Falcon) and a data-analysis agent (Finch) in a loop: hypothesis → experiment proposal → interpret lab data → updated hypothesis; humans ran the wet-lab experiments — [arXiv](https://arxiv.org/pdf/2505.13400), [FutureHouse](https://futurehouse.org/research-announcements/demonstrating-end-to-end-scientific-discovery-with-robin-a-multi-agent-system).
- **DeepScientist**: frames discovery as Bayesian optimisation; hierarchical "hypothesize, verify, analyze" loop with a cumulative **Findings Memory** that promotes promising findings to higher-fidelity validation — [arXiv HTML](https://arxiv.org/html/2509.26603v1).
- **Dolphin**: closed loop of idea generation → experimental verification → results feedback; ideas filtered for topic/task relevance; results labelled improvement / maintenance / decline vs reference code and fed into the next round; traceback-guided debugging — [ACL Anthology](https://aclanthology.org/2025.acl-long.1056).
- **CycleResearcher**: policy model writes papers, CycleReviewer (8B/70B) simulates peer review and provides an RL reward signal — [ICLR](https://proceedings.iclr.cc/paper_files/paper/2025/hash/0a48036026dc7946ef6033ae14719cc5-Abstract-Conference.html), [repo](https://github.com/zhu-minjun/Researcher).
- **TinyScientist**: Engine coordinating Thinker (ideation), Coder, Writer, Reviewer, a Formatter (editable tables), an **MCPClient** for research tools, and a **Checker** that enforces user-set budgets (max experimental runs, max self-reflection steps) — [arXiv HTML](https://arxiv.org/html/2510.06579v1).
- **Biomni**: single agent combining LLM reasoning, retrieval-augmented planning and **code execution** over a large tool/database "data lake" (~11 GB), supports MCP servers; README warns it executes LLM-generated code with full privileges, so sandbox it — [SourcePulse/README summary](https://www.sourcepulse.org/projects/8382188), [repo](https://github.com/snap-stanford/Biomni).
- **ChemCrow**: GPT-4 ReAct-style agent with **18 expert-designed tools** (reaction, molecule, safety, search) and RoboRXN for synthesis; **Coscientist**: GPT-4 planner with modules for web search, documentation search, code execution and robotic-lab APIs — [PMC ChemCrow](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11116106/), [PMC Coscientist](https://pmc.ncbi.nlm.nih.gov/articles/PMC10733136).
- **data-to-paper**: sequential LLM **and rule-based** agents (hypothesis, analysis, writing); "data-chaining" makes every number in the manuscript traceable back to the code line that produced it; autopilot or human-oversight mode — [repo](https://github.com/Technion-Kishony-lab/data-to-paper), [author PDF](https://kishony.technion.ac.il/wp-content/uploads/2024/05/AIoa2400555.pdf).
- **ResearchTown**: research community as an agent–data graph (researchers and papers as nodes); reading, writing and reviewing as **TextGNN** message passing over that graph — [PMLR](https://proceedings.mlr.press/v267/yu25i.html).

### Inferences
- Three memory designs recur and map directly onto Mycelium assets: a **shared world model / findings memory** (Kosmos, DeepScientist) ≈ Mycelium's evidence ledger + project state; a **shared document store** (AgentRxiv) ≈ Mycelium's briefings/reports archive; a **knowledge graph of concepts and papers** (SciAgents, SciMON, ResearchAgent, ResearchTown) ≈ Mycelium's Postgres KG. Mycelium already owns the grounding substrate that these systems build per-run.
- Provenance-by-construction (data-to-paper's data-chaining, Kosmos's claim-to-source links) is the same idea as Mycelium's deterministic citation verifier — evidence that this is the right non-negotiable for any agentic extension.
- TinyScientist's Checker (hard budgets on runs and reflection steps) is the demo-track analogue of Mycelium's "bounded repair"; it shows agentic loops are publishable with explicit caps.

### Gaps
- Could not obtain the co-scientist's quantitative evaluation (Elo vs expert preference, compute scaling curves) from the Nature version; the blog gives none.
- No primary-text confirmation of the AI co-scientist's tool set (web search, specialised models) beyond the blog.

## 3. Evaluation, headline numbers, and independent criticism / replication

### Takeaway
Self-reported results are strong, but every independent audit found serious problems: weak novelty checking, failed or flawed experiments, hallucinated citations, benchmark cherry-picking and post-hoc selection. The best-controlled human study (Si, Yang, Hashimoto) found LLM ideas look more novel on paper but the advantage disappears — and sometimes reverses — once ideas are executed. Benchmarks consistently put end-to-end discovery success at ~25–35%.

### Cited Findings
**Self-reported**
- AI Scientist-v2: three fully AI-generated manuscripts submitted to an ICLR 2025 workshop; one scored 6.33 average (top ~45%); authors concede it struggles to produce genuinely novel high-impact hypotheses — [HF paper page](https://huggingface.co/papers/2504.08066). Sakana withdrew the accepted paper; none reached main-conference level — [danilchenko.dev](https://www.danilchenko.dev/posts/2026-04-06-ai-scientist-v2-first-peer-reviewed-ai-paper/), [Vector Institute](https://vectorinstitute.ai/?p=26786).
- Agent Laboratory: o1-preview gave best outcomes; generated ML code reached SOTA vs existing methods; human feedback improved quality; 84% cost reduction vs prior autonomous research methods (self-reported) — [ACL Anthology](https://aclanthology.org/2025.findings-emnlp.320).
- AgentRxiv: agents with access to prior research improved more than isolated ones; 13.7% relative gain on MATH-500 for shared multi-lab setting; +3.3% average on other benchmarks — [arXiv](https://arxiv.org/pdf/2503.18102).
- CycleReviewer: 26.89% lower MAE than individual human reviewers at predicting scores; CycleResearcher papers 5.36 simulated score vs 5.24 human preprints and 5.69 accepted papers — [search summary of ICLR paper](https://proceedings.iclr.cc/paper_files/paper/2025/hash/0a48036026dc7946ef6033ae14719cc5-Abstract-Conference.html) (simulated review, not human).
- DeepScientist: >20,000 GPU hours, ~5,000 ideas, ~1,100 experimentally validated, beat 2025 SOTA by 183.7% / 1.9% / 7.9% on three tasks (agent failure attribution, LLM inference acceleration, AI-text detection) — [arXiv HTML](https://arxiv.org/html/2509.26603v1); a community summary says only 21 ideas led to genuine innovations — [HF papers](https://huggingface.co/papers/2509.26603) (definitions differ).
- Kosmos: 79.4% of statements in reports judged accurate by independent scientists; 7 highlighted discoveries (3 reproduce unpublished/preprinted findings, 4 novel); valuable findings scale ~linearly with cycles up to 20; collaborators estimated a 20-cycle run ≈ 6 months of their research time — [arXiv](https://arxiv.org/abs/2511.02824).
- Robin: proposed ripasudil (ROCK inhibitor) as a dry-AMD candidate and an RNA-seq follow-up implicating ABCA1; wet-lab work by humans — [arXiv](https://arxiv.org/pdf/2505.13400).
- Virtual Lab: designed 92 nanobodies, two bound spike proteins of recent SARS-CoV-2 variants in lab tests — [Biohub](https://biohub.org/?p=40708), [EurekAlert](https://www.eurekalert.org/news-releases/1092265).
- AI co-scientist: wet-lab-supported hypotheses in liver fibrosis (drug candidate blocking 91% of a scarring-linked response), aging and infectious disease; no equal-compute baselines reported on the blog — [DeepMind blog](https://deepmind.google/blog/co-scientist-a-multi-agent-ai-partner-to-accelerate-research/).
- ChemCrow: human evaluators scored 9.24/10 vs 4.79/10 for GPT-4 alone — [search summary of PMC article](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11116106/).
- SciMON: ideas improve over baselines but remain "incremental and with insufficient detail" and fall far behind real papers in novelty, depth, utility (authors' own human eval) — [arXiv](https://arxiv.org/abs/2305.14259v5).
- ResearchAgent: human and model-based evaluation show novel, clear, valid ideas; gains diminish after a few refinement cycles — [arXiv](https://arxiv.org/abs/2404.07738).
- Scideator: 22 CS researchers reported more creativity support than a same-LLM baseline without facet modules; participants lowered novelty ratings when the checker flagged non-novelty; checker agreement with human novelty ratings reported >10x better than a prior LLM novelty method — [arXiv](https://arxiv.org/abs/2409.14634v5).
- data-to-paper: authors say novelty of produced manuscripts was "relatively limited" and the system targets simple goals and datasets; secondary summary reports 80–90% correctness on simple goals and 10–20% critical errors in open-goal mode (unverified) — [Substack review](https://drloock.substack.com/p/journal-article-review-autonomous).

**Benchmarks**
- ScienceAgentBench: 102 tasks from 44 papers in 4 disciplines; best agent 32.4% independently, 34.3% with expert knowledge (Claude 3.5 Sonnet + self-debug); direct prompting 16.7% — [mlanthology](https://mlanthology.org/iclr/2025/chen2025iclr-scienceagentbench), [alphaxiv overview](https://alphaxiv.org/overview/2410.05080v3).
- DiscoveryBench: 264 real tasks from papers across 6 domains + 903 synthetic; best system ~25% — [arXiv](https://arxiv.org/abs/2407.01725).
- AstaBench: >2,400 problems (literature understanding, code/execution, data analysis, end-to-end discovery), scores cost as well as quality; 57 agents across 22 classes; "far from solving science research assistance"; no commercial agent could perform the full task range; open-weight models lag closed ones — [AI2 blog](https://allenai.org/blog/astabench); spring 2026 update adds new frontier results — [AI2 update](https://allenai.org/blog/astabench-update-spring-2026).
- LAB-Bench: 2,457 MCQs across 8 categories (LitQA2, SeqQA, DbQA, figures, tables, protocols); 20% held out privately against contamination — [FutureHouse](https://futurehouse.org/articles/lab-bench-measuring-capabilities-of-language-models-for-biology-research), [HF card](https://www.huggingface.co/datasets/futurehouse/lab-bench/blob/bdaa357826a7ba4e048ad77e9089183042c95204/README.md).
- ResearchBench (Liu/Yang): inspiration retrieval / hypothesis composition / ranking over 2024 papers from 12 disciplines; LLMs relatively good at inspiration retrieval — [arXiv](https://arxiv.org/pdf/2503.21248).
- MOOSE-Chem benchmark: 51 high-impact chemistry papers published after Jan 2024, annotated by PhD chemists — [ICLR proceedings](https://proceedings.iclr.cc/paper_files/paper/2025/hash/51fd9a7d1706023cb9f8210cc6ac357c-Abstract-Conference.html).
- IdeaBench: 2,374 biomedical target papers + 29,408 references — [arXiv](https://arxiv.org/abs/2411.02429v1).

**Independent criticism / replication**
- Beel, Kan, Baumgart, "Evaluating Sakana's AI Scientist…" (*SIGIR Forum* 2025, arXiv 2502.14297): literature review relies on simple keyword search → poor novelty assessment; 5 of 12 experiments (42%) failed from coding errors; manuscripts had few/outdated citations (median 5), missing figures, placeholder text; positive commentators had not tested the system themselves — [arXiv](https://arxiv.org/abs/2502.14297); reviewer agent rejected 9 of 10 human OpenReview papers including 4 accepted ones (from [alphaxiv overview](https://www.alphaxiv.org/overview/2502.14297v3), secondary).
- Luo, Kasirzadeh, Shah (CMU), "The More You Automate, the Less You See: Hidden Pitfalls of AI Scientist Systems", arXiv 2509.08713 (NeurIPS 2025 AI4Science workshop spotlight): four failure modes — inappropriate benchmark selection, data leakage, metric misuse, post-hoc selection bias; AI Scientist v2 chose easy benchmarks 47.1% of the time when shown SOTA numbers vs 18.0% without; systems favoured candidates with good test scores despite poor train/val (p-hacking analogue); access to logs/code substantially raises auditors' detection accuracy; recommends mandatory submission of traces — [arXiv](https://arxiv.org/abs/2509.08713), [arXiv HTML v2](https://arxiv.org/html/2509.08713v2).
- Si, Yang, Hashimoto (Stanford): 100+ NLP researchers judged LLM ideas more novel than expert ideas (p<0.05) but slightly less feasible; LLM self-evaluation unreliable and generations lack diversity — [arXiv 2409.04109](https://arxiv.org/abs/2409.04109). Follow-up "The Ideation-Execution Gap" (43 experts executed randomly assigned ideas; ICLR 2026 poster): after execution LLM-idea scores dropped significantly more than human ones on all metrics, sometimes flipping the ranking — [arXiv 2506.20803](https://arxiv.org/pdf/2506.20803), [ICLR](https://iclr.cc/virtual/2026/poster/10010564).
- Agents4Science 2025 (AI-first-author conference): 315 submissions, 62 desk-rejected incomplete, 3 LLM reviewers + human review of top 79, 48 accepted; GPT-5 reviewer harshest (avg 2.30), Gemini 2.5 Pro most lenient (4.23), Claude Sonnet 4 in between (3.0); authors reported AI errors needing human intervention; two papers rejected for prompt injection — [arXiv 2511.15534](https://arxiv.org/pdf/2511.15534); press reports hallucinated references and redundant code/text — [SCMP](https://www.scmp.com/news/china/science/article/3331218/why-ai-scientists-fail-impress-human-experts-one-kind-online-conference).

### Inferences
- LLM-as-reviewer scores are not a reliable success metric: reviewer models disagree by ~2 points on the same papers (Agents4Science) and Sakana's reviewer is strongly conservative on human papers (Beel et al.). Any Mycelium hypothesis-engine evaluation that uses an LLM judge needs human calibration and intervals — consistent with Mycelium's own finding that LLM rerankers add no signal.
- The ideation-execution gap is the single most important result for a lab hypothesis engine: novelty judged at proposal time is a poor proxy for value; evaluation should include whether the lab actually pursued the idea and what happened.

### Gaps
- No independent replication of Kosmos, AI co-scientist, Robin or DeepScientist numbers was found.
- Could not confirm whether Luo et al. audited Agent Laboratory as the second system (summary says "both systems").

## 4. How these systems differ from Mycelium

### Takeaway
Nearly all systems optimise for autonomy on a single research question supplied per run, with grounding in public literature and (sometimes) a dataset; none is grounded in a specific lab's ongoing context (chat, project state, members' papers, deadlines) or runs as a standing, scheduled service for a group. Mycelium's differentiator is continuous, consented, lab-scoped grounding plus deterministic verification — the exact areas where audits found autonomous systems weakest.

### Cited Findings
- Agent Laboratory explicitly positions itself as executing a **human scientist's own idea** rather than generating ideas — closest in philosophy to an assistant — [ACL Anthology](https://aclanthology.org/2025.findings-emnlp.320).
- IRIS and Scideator are human-in-the-loop ideation tools for an individual researcher (user steers MCTS / recombines facets), evaluated via user studies (IRIS: researchers from diverse disciplines; Scideator: 22 CS researchers) — [ACL Anthology](https://aclanthology.org/2025.acl-demo.57), [arXiv](https://arxiv.org/abs/2409.14634v5).
- Virtual Lab is the closest analogue to a "lab": an AI PI + specialists + critic with a human giving high-level feedback, but the "lab" is simulated agents, not the human lab's own context — [Freethink](https://www.freethink.com/artificial-intelligence/virtual-lab-interdisciplinary-research).
- Kosmos/Robin ground on a provided dataset plus literature, with a per-run world model discarded/archived after a ≤12 h run — [arXiv](https://arxiv.org/abs/2511.02824).
- AgentRxiv's cross-run memory is a store of agent-written reports, not human lab records — [arXiv](https://arxiv.org/pdf/2503.18102).
- The only "team memory" architecture found (Goldilocks, EMNLP 2026 demo: private + shared team tiers with a sufficiency gate) is a general assistant, not a research one — [papers.cool listing](https://papers.cool/venue/2026.emnlp-demos.16@ACL) (unverified detail).

### Inferences
- Positioning for Mycelium's papers: "lab-grounded, continuous, verifiable research assistance" vs "per-question autonomous research". The audits (Beel; Luo et al.; Agents4Science) supply the motivation: autonomous systems fail on novelty checking, citation hygiene and selective reporting — things a lab-grounded system with deterministic verifiers can address by construction.
- Mycelium's KG of members' paper facets (methods/datasets/tasks) is structurally the same input that Scideator (purpose/mechanism/evaluation facets), SciMON (KG + citation inspirations) and ResearchAgent (entity store + citation graph) build ad hoc — but scoped to the lab, which none of them do.

### Gaps
- No system found that ingests a lab's private chat with consent for research purposes; absence is based on this search only, not exhaustive.

## 5. What Mycelium could take (patterns, components, benchmarks, baselines)

### Takeaway
The highest-value borrowings are evaluation protocols and verification patterns, not agent frameworks: facet-based novelty checking (Scideator), inspiration-retrieval decomposition and benchmarks (MOOSE-Chem/ResearchBench), claim-to-source provenance (Kosmos, data-to-paper), trace-based auditing for the four pitfalls (Luo et al.), budget caps (TinyScientist), cost-aware scoring (AstaBench), and execution-outcome evaluation (Si et al.).

### Cited Findings / concrete borrowings
- **Novelty checker for the hypothesis engine**: Scideator's Idea Novelty Checker (retrieve related papers, LLM judges against an explicit facet-based novelty definition, short explanation) reported >10x better agreement with humans than a prior LLM novelty method — [arXiv](https://arxiv.org/abs/2409.14634v5). Mycelium already extracts methods/datasets/tasks facets; mapping them to purpose/mechanism/evaluation makes this a near-drop-in pipeline stage with a deterministic retrieval step.
- **Inspiration retrieval as the core subtask**: MOOSE-Chem/ResearchBench decompose hypothesis generation into background + inspiration retrieval + composition + ranking, and find LLMs relatively good at inspiration retrieval — [arXiv](https://arxiv.org/pdf/2503.21248). Mycelium's nightly retrieval over interest clusters is an inspiration retriever; ResearchBench and MOOSE-Chem's 51-paper set are ready offline benchmarks (contamination-controlled by publication date).
- **Claim provenance**: Kosmos links every report claim to the analysis/source it came from — [arXiv](https://arxiv.org/abs/2511.02824); data-to-paper chains numbers to code lines — [repo](https://github.com/Technion-Kishony-lab/data-to-paper). Extend Mycelium's citation verifier from "citation exists and matches" to "every claim has a typed provenance edge" (Observation id, paper id, project-state field).
- **Shared findings memory**: Kosmos's world model and DeepScientist's Findings Memory (promote promising findings to higher-fidelity validation) — [arXiv HTML](https://arxiv.org/html/2509.26603v1) — suggest a "lab findings ledger" layered on the evidence ledger: hypotheses with status (proposed → checked → pursued → outcome), which also supplies the execution-outcome labels Si et al. show are needed.
- **Tournament ranking (with caution)**: co-scientist's Elo tournament of pairwise comparisons — [DeepMind blog](https://deepmind.google/blog/co-scientist-a-multi-agent-ai-partner-to-accelerate-research/); Chain of Ideas' Idea Arena — [ACL Anthology](https://aclanthology.org/2025.findings-emnlp.477). Mycelium's own LLM-rerank position-bias finding implies any pairwise LLM judging needs order-swapping and intervals.
- **Budget/controllability caps**: TinyScientist's Checker bounds experimental runs and self-reflection steps; MCP client for tools — [arXiv HTML](https://arxiv.org/html/2510.06579v1). A good template for introducing tool-calling into Mylo without unbounded loops.
- **Trace auditing**: Luo et al. show logs + code dramatically improve detection of benchmark cherry-picking, leakage, metric misuse and post-hoc selection — [arXiv](https://arxiv.org/abs/2509.08713). For an agentic Mycelium: persist full tool-call traces per run and run deterministic checks for those four pitfalls.
- **Cost-aware evaluation**: AstaBench reports cost alongside quality — [AI2 blog](https://allenai.org/blog/astabench); relevant to Mycelium's nightly budget in `mycelium.toml`. Its literature-understanding tasks (PaperFindingBench, LitQA2-FullText-Search) are directly applicable to Mycelium's retrieval — [AI2 blog](https://allenai.org/blog/astabench).
- **Baselines for a Mycelium hypothesis-engine paper**: SciMON, ResearchAgent, Chain of Ideas (open code, Apache-2.0/none), IRIS (open demo), Scideator (human-study design), AI Scientist idea stage. Human-study protocol to copy: Si et al. blind expert ratings + execution follow-up — [arXiv](https://arxiv.org/abs/2409.04109), [arXiv](https://arxiv.org/pdf/2506.20803).
- **Shared cross-lab memory**: AgentRxiv's preprint-server idea (13.7% relative MATH-500 gain from sharing) — [arXiv](https://arxiv.org/pdf/2503.18102) — maps to department-level sharing of lab findings in Mycelium's department profile, but only measured on toy ML tasks.
- **Literature agent component**: PaperQA (Apache-2.0, actively maintained) — [repo](https://github.com/Future-House/paper-qa); Biomni shows MCP-based tool integration and warns to sandbox code execution — [repo](https://github.com/snap-stanford/Biomni).

### Inferences
- The lowest-risk path to "agentic Mycelium" is agentic stages inside the existing pipeline (tool-calling literature lookups, novelty checks, bounded repair) with a persistent findings ledger, rather than a free-running multi-agent lab; this matches where the evidence is (see section 6).
- An IUI 2028 hypothesis-engine study could be distinguished from IRIS/Scideator by (a) lab-level rather than individual users, (b) grounding in the lab's ledger/KG, (c) measuring execution uptake over weeks, not just proposal-time ratings.

### Gaps
- No public benchmark exists for lab-grounded (private-context) hypothesis generation; Mycelium would need to build one (e.g., held-out future papers of the lab's members as ground truth, mirroring MOOSE-Chem's post-cutoff design).

## 6. Cross-cutting lessons: which agent patterns have evidence behind them

### Takeaway
Evidence supports (1) iterative search over candidates with external verification (code execution, data, literature), (2) persistent shared memory across long runs, (3) human-in-the-loop steering, and (4) provenance/traceability. Evidence is weak or absent for (5) role-play multi-agent decomposition per se — no system in this list reports a matched-compute single-agent baseline, and the one controlled study (Tran & Kiela) finds single agents match or beat multi-agent systems at equal thinking-token budgets; and (6) LLM-as-reviewer as a success signal.

### Cited Findings
- **Matched-compute evidence against multi-agent gains**: Tran & Kiela (Stanford, arXiv 2604.02460, Apr 2026) find single-agent systems match or beat multi-agent systems at matched thinking-token budgets on FRAMES and 4-hop MuSiQue across Qwen3, DeepSeek-R1, Gemini 2.5; multi-agent regains competitiveness only when the single agent's context is corrupted (masking/substitution); budget control for Gemini is approximate — [arXiv](https://arxiv.org/abs/2604.02460), [DEV summary](https://dev.to/greza_dev/why-single-agents-beat-multi-agent-systems-at-equal-token-budgets-445c).
- **Multi-agent failure taxonomy**: Cemri et al. (NeurIPS 2025) MAST — 14 failure modes in 3 categories; 1,642 annotated traces (v3) across 7 MAS frameworks; κ=0.88 human agreement, κ=0.77 LLM-judge vs experts — [arXiv HTML v3](https://arxiv.org/html/2503.13657v3); repo [multi-agent-systems-failure-taxonomy/MAST](https://github.com/multi-agent-systems-failure-taxonomy/MAST) (~434 stars).
- **No matched-compute baselines reported** by co-scientist's blog ("reports no comparisons against other systems or equal-compute baselines") — [DeepMind blog](https://deepmind.google/blog/co-scientist-a-multi-agent-ai-partner-to-accelerate-research/); Virtual Lab reports no critic ablation in sources found — [Freethink](https://www.freethink.com/artificial-intelligence/virtual-lab-interdisciplinary-research) (gap).
- **Compute scaling within one system does help**: Kosmos valuable findings scale ~linearly with cycles up to 20 — [arXiv](https://arxiv.org/abs/2511.02824); IRIS uses MCTS explicitly to scale test-time compute — [ACL Anthology](https://aclanthology.org/2025.acl-demo.57). But ResearchAgent's refinement gains diminish after a few cycles — [arXiv](https://arxiv.org/abs/2404.07738).
- **Execution feedback is what makes autonomy work**: ScienceAgentBench — self-debug (execution feedback) 32.4% vs direct prompting 16.7% for the same model — [alphaxiv overview](https://alphaxiv.org/overview/2410.05080v3); Dolphin's improvement/maintenance/decline feedback loop — [ACL Anthology](https://aclanthology.org/2025.acl-long.1056).
- **Shared memory helps** (weakly evidenced): AgentRxiv agents with prior-research access outperform isolated ones — [arXiv](https://arxiv.org/pdf/2503.18102); Kosmos attributes long-horizon coherence over 200 rollouts to the world model — [arXiv](https://arxiv.org/abs/2511.02824) (no ablation reported in the abstract).
- **Human feedback helps**: Agent Laboratory reports human feedback significantly improves research quality — [ACL Anthology](https://aclanthology.org/2025.findings-emnlp.320); Agents4Science notes AI errors that required human intervention — [arXiv](https://arxiv.org/pdf/2511.15534).
- **Literature grounding / novelty is the weakest link**: keyword-search lit review → poor novelty assessment (Beel et al. [arXiv](https://arxiv.org/abs/2502.14297)); LLM ideas lack diversity and self-evaluation is unreliable (Si et al. [arXiv](https://arxiv.org/abs/2409.04109)); ideas incremental (SciMON [arXiv](https://arxiv.org/abs/2305.14259v5)).
- **Autonomy hides methodological sins**: benchmark cherry-picking and post-hoc selection (Luo et al. [arXiv](https://arxiv.org/abs/2509.08713)); 42% experiment failure (Beel et al.).

### Inferences
- For Mycelium: add tool calling and memory, but treat "multi-agent" as an implementation detail to justify with a matched-token single-agent ablation, not a feature. Role decomposition (generator/critic/ranker) can be expressed as stages of one agent with structured outputs, which is what Mycelium already does.
- The pattern with the strongest evidence and best fit is "generate many → verify against external ground truth deterministically → keep a ledger". Mycelium's verifiers are the ground-truth side; the agentic upgrade should spend compute on more candidates and more verification, not on inter-agent conversation.
- Any claim in Mycelium's own papers about agentic gains should report tokens/cost (AstaBench-style) and include a single-agent equal-budget baseline, given Tran & Kiela and MAST.

### Gaps
- No paper in this catalogue directly compares a multi-agent science system with a single agent at matched compute; this is an open evaluation gap Mycelium could fill.
- I did not read the full co-scientist Nature paper, which may contain internal ablations or test-time-compute curves.
