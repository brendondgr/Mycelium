# Give Mylo tools, keep the verifiers

Mycelium should become agentic by putting **one tool-calling agent over its existing deterministic services**, not by adopting a multi-agent "AI scientist" framework. The strongest systems in this space are mostly fixed pipelines with LLM decision points. Ai2's Scholar QA and Paper Finder are hand-coded pipelines with a router ([Paper Finder README](https://github.com/allenai/asta-paper-finder)). Only a handful, PaperQA2, PaSa, GPT-Researcher and Co-STORM among them, let a model choose its actions ([PaperQA2](https://github.com/Future-House/paper-qa)). Every independent audit of autonomous-science systems found the failures sit in exactly the places Mycelium already enforces deterministically: weak novelty checks, hallucinated or thin citations, and selective reporting ([Beel et al.](https://arxiv.org/abs/2502.14297); [Luo et al.](https://arxiv.org/abs/2509.08713)). The one matched-compute study finds single agents match or beat multi-agent systems at equal thinking-token budgets ([Tran & Kiela](https://arxiv.org/abs/2604.02460)). No published system combines Mycelium's lab scope, push delivery, consent-gated chat evidence, verified reports and CPU self-hosting; the closest neighbours each cover two of those at most. The concrete borrowings are cheap and mostly permissively licensed. Graphiti's bi-temporal edges belong in the ledger, PaperQA2 and GROBID become on-demand tools, Media-to-Insights' cheap-prefilter watchers deliver intraday updates, and PydanticAI output validators keep "one bounded repair". Mycelium's weakest point is evaluation, not architecture: it has **no human-judged results**, while every comparable demo reports a user study or an annotated benchmark. Fixing that matters more for the NAACL 2027 demo (due 2026-12-04) than any agent loop.

All star counts, licences and last-push dates below are GitHub API snapshots taken on 2026-11-08. **DEMO** marks a system-demonstration-track paper. "Unverified" carries forward the notes' own flags.

## Most "agents" here are pipelines, and four families matter to Mycelium

The literature splits into four families: pull-based literature assistants and push feeds; autonomous science and hypothesis agents; extraction and knowledge-graph tools; and agent memory and infrastructure. Across all four, the pattern is that **almost every system is individual, pull-based and session-scoped**: a user asks, the system answers, and the context is discarded. Kosmos keeps a world model, but only for a run of up to 12 hours ([Kosmos](https://arxiv.org/abs/2511.02824)). AgentRxiv's cross-run memory stores agent-written reports, not lab records ([AgentRxiv](https://arxiv.org/pdf/2503.18102)). Mycelium is the inverse: lab- and department-scoped, scheduled, persistent, and consent-gated, but without tool choice or interactive deep QA.

## Each area lends a different kind of improvement

The useful contributions differ by family. Literature systems lend **tools and report-writing patterns**. Autonomous-science systems lend **verification and evaluation protocols**, but not code. Extraction tools lend **dependencies and benchmarks**. Memory systems lend **a data model and a runtime library**. The tables classify each candidate as adopt-as-dependency (D), wrap-as-agent-tool (T), borrow-the-pattern (P) or use-as-benchmark-or-baseline (B). Cost ratings are the notes' README-based judgments, not measurements.

### Literature assistants: one tool, one router, one report pattern

The highest-yield single move is **wrapping PaperQA2 as a `/mylo ask` tool** over the member-paper corpus Mycelium already ingests. It is an Apache-2.0 pip package that runs on any LiteLLM provider and checks retractions ([PaperQA2](https://github.com/Future-House/paper-qa)). The catch is that it keeps its own index, so Mycelium would index papers twice. Nobody has checked whether PaperQA2 can point at an external pgvector store. The cheapest honest "agentic" step is **Paper Finder's pattern**: an LLM parses the request into a structured object, and a planner routes it to an intent-specific deterministic workflow ([Paper Finder](https://github.com/allenai/asta-paper-finder)). Mycelium's equivalents are feed search, KG lookup, project-state query and opportunity search. For the Monday weekly, Scholar QA's **quote extraction, then outline and quote clustering, then section-by-section generation** fits the citation verifier naturally, because every sentence starts from a verbatim quote ([Scholar QA](https://github.com/allenai/ai2-scholarqa-lib)). Scholar QA also uses the mxbai-rerank-large reranker. Mycelium's own experiments refuted cross-encoder reranking on short queries, so that reranker is a measure-first candidate, not an adoption.

### Autonomous science: verification patterns, not frameworks

These systems are most valuable as **evidence about what fails** and as sources of evaluation protocol. **Scideator's novelty checker** retrieves related papers and judges novelty against an explicit facet definition. Its authors report human agreement more than 10x better than a prior LLM novelty method ([Scideator](https://arxiv.org/abs/2409.14634v5)). Mycelium already extracts methods, datasets and tasks, so mapping them onto purpose, mechanism and evaluation makes the checker close to a drop-in stage. **Kosmos and data-to-paper** show that provenance by construction is publishable: every claim links to its source, and every number to the code line that produced it ([Kosmos](https://arxiv.org/abs/2511.02824); [data-to-paper](https://github.com/Technion-Kishony-lab/data-to-paper)). That argues for extending the citation verifier from "the citation exists and matches" to "every claim has a typed provenance edge": an Observation id, a paper id or a project-state field. **TinyScientist's Checker**, with hard caps on runs and self-reflection steps, shows a demo track accepts agent loops when they are explicitly bounded ([TinyScientist](https://arxiv.org/html/2510.06579v1)). Luo et al. found that logs and code substantially raise auditors' ability to detect cherry-picking and leakage, so an agentic Mycelium should **persist every tool-call trace** ([Luo et al.](https://arxiv.org/abs/2509.08713)).

### Extraction and KG: full text, external IDs and a real benchmark

The extraction field exposes three gaps in Mycelium: **input** (mostly titles and abstracts), **identity** (concepts have no external IDs) and **evaluation** (a synthetic set; linker recall 0.658 to 0.775, zero wrong merges). SciER annotated full text precisely because abstract-only annotation misses body-text mentions ([SciER](https://aclanthology.org/2024.emnlp-main.726)), so Mycelium's facet recall is capped by its input, not only by its extractor. **GROBID in CRF mode** is the proven CPU parser: about 10.6 PDFs/s sustained on 16 CPUs, shipped as a Docker image, with sections, citation contexts and coordinates ([GROBID](https://github.com/grobidOrg/grobid)). It suits a `parse_paper` tool that fetches a methods section on demand rather than pre-parsing everything. For graph-native retrieval, HippoRAG 2's Personalized PageRank gained +7.7 points on associativity tasks ([HippoRAG 2](https://proceedings.mlr.press/v267/gutierrez25a.html)). The notes recommend **porting the algorithm into Postgres** (recursive SQL, or networkx on a lab-sized subgraph) rather than taking the dependency, because each graph-RAG library brings its own storage.

### Memory and frameworks: four columns and a library

The notes are explicit: **do not adopt a memory product wholesale**. Graphiti's model stamps each fact with transaction time (created, expired) and validity time (valid, invalid), and invalidates contradicted facts instead of deleting them ([Zep paper](https://arxiv.org/html/2501.13956)). Mycelium's ledger already supersedes and retracts. Adding the four timestamps to Observations and KG edges answers "what did the lab believe on date X" in plain Postgres, with no graph database. One distinction the memory systems miss is worth keeping: **a retraction or consent withdrawal is not a belief change**. It should tombstone the fact and propagate to everything derived from it, and neither Zep nor Mem0 addresses deletion at all ([Zep paper](https://arxiv.org/html/2501.13956); [Mem0 paper](https://arxiv.org/html/2504.19413v1)). For the runtime, **PydanticAI** maps one-to-one onto Mycelium's discipline. Tools are plain typed functions. Output validators raise `ModelRetry`, and the output retry budget defaults to 1, which is "one bounded repair" ([PydanticAI](https://pydantic.dev/docs/ai/core-concepts/output/)).

## Mycelium's niche is lab scope plus consent plus verification, and the audits show why it matters

Mycelium is ahead of this field in one specific way, not in general. Its lead is the **intersection** of lab or department scope, push delivery, consent-gated chat evidence, a verified weekly report and self-hosting. Most feeds are individual recommenders: Scholar Inbox trains on individual ratings ([Scholar Inbox](https://aclanthology.org/2025.acl-demo.30/)), and Arxiv Copilot builds per-user profiles ([Arxiv Copilot](https://arxiv.org/html/2409.04593v1)). PaperBee posts to lab Slack channels but has no verifier, KG or paper ([PaperBee](https://github.com/theislab/paperbee)). CHOIR is the only published lab-scoped chat assistant, and it answers on demand from lab documentation, not from the literature ([CHOIR](https://choir.cs.vt.edu/)). Nothing found combines grants, fellowships and conference calls with a literature feed, though that absence comes from a non-exhaustive search. The notes also found **no paper on per-person consent for an ambient Slack or Discord listener**, and none on propagating consent withdrawal to derived memories.

The critiques of autonomous science are the strongest evidence that this niche is valuable rather than merely empty. Beel et al. found that Sakana's AI Scientist reviewed literature with simple keyword search. **5 of 12 experiments (42%) failed** from coding errors, and its manuscripts cited a median of 5 sources ([Beel et al.](https://arxiv.org/abs/2502.14297)). Luo et al. found AI Scientist v2 **chose easy benchmarks 47.1% of the time when shown SOTA numbers, against 18.0% without them** ([Luo et al.](https://arxiv.org/abs/2509.08713)). In Si et al., more than 100 NLP researchers rated LLM ideas more novel than expert ideas ([Si et al.](https://arxiv.org/abs/2409.04109)). After 43 experts executed the ideas, that advantage shrank and sometimes reversed ([ideation-execution gap](https://arxiv.org/pdf/2506.20803)). At Agents4Science, LLM reviewers disagreed by about two points on the same papers (GPT-5 averaged 2.30, Gemini 2.5 Pro 4.23), and two papers were rejected for prompt injection ([Agents4Science](https://arxiv.org/pdf/2511.15534)). Benchmarks put end-to-end success low: the best ScienceAgentBench agent solved **32.4%** of tasks ([mlanthology](https://mlanthology.org/iclr/2025/chen2025iclr-scienceagentbench)), the best DiscoveryBench system about 25% ([DiscoveryBench](https://arxiv.org/abs/2407.01725)), and AstaBench calls research assistance "far from solved" ([AstaBench](https://allenai.org/blog/astabench)). Even Kosmos, the best-reported system, had **79.4%** of report statements judged accurate, so roughly one statement in five was not ([Kosmos](https://arxiv.org/abs/2511.02824)). Against this record, Mycelium's deterministic citation verifier, grounding checks and bounded repair are its scarcest asset.

The privacy literature points the same way. In CIMemories, frontier models reached up to **69% attribute-level violations**, and GPT-5's violation rate grew from 0.1% to 9.6% as usage went from 1 to 40 tasks. Privacy prompting did not fix it ([CIMemories](https://arxiv.org/abs/2511.14937)). That favours what Mycelium already does: filter by consent and visibility in SQL **before** the model sees anything. A 2026 preprint, known only by title, names this pattern "authorization before context" ([arXiv 2608.17148](https://arxiv.org/pdf/2608.17148)). Mycelium also keeps no raw chat text, only a short-lived buffer. Zep and Mem0 both trace facts back to stored raw episodes, so Mycelium's **text-free, consent-scoped provenance** is a real point of difference ([Zep paper](https://arxiv.org/html/2501.13956)).

Mycelium is behind in four areas. First, it has **no interactive deep QA**, and reviewers will judge any "agentic" claim against PaperQA2, Scholar QA and open_deep_research. Second, its graph is built from abstracts and has no external IDs, while CS-KG, S2AG and SemOpenAlex give stable identifiers at scale ([CS-KG](https://oro.open.ac.uk/85306)). Third, its feed is driven by declared interests and watch topics, while Scholar Inbox and PaperFlow learn from ratings and model interest drift ([PaperFlow](https://arxiv.org/abs/2606.07454)). It also lacks PaSa's citation-expansion retrieval channel. Fourth, and most serious, its evidence is **synthetic only**. The ledger's 91.7% recall of planted statements and zero harm violations are a good engineering signal, but comparable demos report human evidence. Scholar Inbox used 800k ratings plus a user study, CHOIR a one-month deployment in 4 labs with 21 participants ([CHOIR](https://choir.cs.vt.edu/)), and SciTrue 300 human-evaluated attributions ([SciTrue](https://aclanthology.org/2026.eacl-demo.27/)). Steelmanning the multi-agent side, Tran & Kiela found multi-agent systems regain ground when a single agent's context is corrupted ([Tran & Kiela](https://arxiv.org/abs/2604.02460)). An agent reading noisy lab chat could hit that condition, so the single-agent default should be tested, not assumed.

## A six-stage path keeps deterministic code in charge of what is seen and what is committed

The governing rule throughout is **"the model chooses tools; deterministic code decides visibility and commits."** Every stage puts the user's authorization inside the tool, keeps the verifiers as output validators, and adds an evaluation gate recorded under `docs/research/experiments/`. One cost is still unmeasured: a tool loop multiplies LLM calls, and nobody has benchmarked its latency or cost through Mycelium's proxy on the CPU host. That measurement belongs in Stage 0, before anything ships.

Stage 4 is where "quicker, more frequent updates" is actually won, and **it is mostly not an agent problem**. Media-to-Insights cut agent calls by about 20% with a keyword-then-semantic matcher and batched extraction from 7 calls to 2 per article ([Media-to-Insights](https://aclanthology.org/2026.acl-demo.44/)). Mycelium's own finding that nothing beats BM25 makes a BM25 trigger the natural cheap first gate. The agent's job is the last step: explaining a hit against the lab's project state, under a budget. Stages 0 through 3 are prerequisites, because an intraday alert that is wrong or leaks private chat costs more trust than a nightly one. Across all stages, any multi-agent decomposition must justify itself against a single agent at an equal token budget. Role splits such as generator, critic and ranker stay as stages of one agent with structured outputs ([Tran & Kiela](https://arxiv.org/abs/2604.02460); [MAST](https://arxiv.org/html/2503.13657v3)).

## The NAACL demo must stand apart from OneKE, Hindsight and two feed demos

Prior demo-track art is abundant, so the bar is the **combination**, not "RAG over papers". Five literature or research-assistant demos were accepted in each of 2024 and 2025, ACL 2026 had about a dozen science-tooling demos, and no NAACL 2026 demo volume exists, so NAACL 2027 is the next one ([EMNLP 2025 demos](https://aclanthology.org/volumes/2025.emnlp-demos/); [ACL 2026 demos](https://aclanthology.org/volumes/2026.acl-demo/)). Because this demo is about the language → KG layer, the must-cite neighbours fall into three groups. On extraction: PaperMage, the document substrate ([EMNLP 2023 demo](https://aclanthology.org/2023.emnlp-demo.45)); DeepKE, an extraction toolkit ([EMNLP 2022 demo](https://aclanthology.org/2022.emnlp-demos)); and **OneKE**, agentic schema-guided extraction with reflection, a WWW 2025 demo ([arXiv](https://arxiv.org/abs/2412.20005v2)). On scholarly graphs: NLP-KG, a field-level scholarly KG ([ACL 2024 demo](https://aclanthology.org/2024.acl-demos.13/)), and GraphMind, graph-based novelty assessment ([EMNLP 2025 demo](https://aclanthology.org/2025.emnlp-demos.21/)). On memory: **Hindsight**, structured agent memory on Postgres + pgvector ([ACL 2026 demo](https://aclanthology.org/2026.acl-demo.27/)). The notes disagree here. The memory notes found no 2025 demo for any memory system, but Hindsight is an ACL 2026 demo, and an unverified EMNLP 2026 demo, "Who Is Asking?" (Goldilocks), adds private plus shared team memory tiers ([papers.cool listing](https://papers.cool/venue/2026.emnlp-demos.16@ACL)). The open niche is **consent-scoped lab memory**, not agent memory in general. For the feed and verification framing, cite Arxiv Copilot and Scholar Inbox as personalised-feed demos, Media-to-Insights as continuous monitoring, SciTrue, FactSearch and CiteLab for verification, and SlackAgents for chat. Two leads, ToFu and ScheMatiQ, came only from a search summary; open them before citing.

The defensible positioning is a **typed, grounded, temporal, consent-scoped lab KG maintained from heterogeneous lab language (papers, project documents, consented chat) on a CPU host**. Each neighbour lacks part of that. OneKE has no time, consent or lab scope; Hindsight and Graphiti model time but not consent or retraction; NLP-KG and CS-KG are field-scoped. None of the demo neighbours handles project state or consented chat. With 26 days to the deadline, the evaluation package should favour runs that are cheap and that reviewers recognise. SciER, including its out-of-distribution split, gives facet F1 ([SciER](https://aclanthology.org/2024.emnlp-main.726)); SciDMT or DMDD give mention-to-concept linking ([DMDD](https://aclanthology.org/2023.tacl-1.64)). Mycelium's grounding-check pass rate and repair yield are numbers no competing demo reports. A retraction-propagation test and a small CI-leakage probe modelled on CIMemories show the consent claim working. Most important is **a small human-judged slice**, because "synthetic only" is the easiest rejection. If the demo shows any tool-choosing behaviour, it should report tokens and cost in the AstaBench style, with an equal-budget comparison against the fixed pipeline. Otherwise, call it "pipelines with an LLM router", which is Ai2's own shipped design and is not a weakness. ResearStudio's plan-as-document view is a ready pattern for showing the agent's trace and the verifier's verdicts live on screen ([ResearStudio](https://aclanthology.org/2025.emnlp-demos.69/)). MCP, skills and the hypothesis engine are not needed for this deadline.

## Conclusion

The field's evidence inverts the usual "agentic" roadmap. The parts of Mycelium that look least agentic are its deterministic verifiers, its consent gate applied before context, and its bounded repair. Those are exactly what autonomous-science audits found missing, so the agentic upgrade should **spend compute on more candidates and more verification, not on agents talking to each other**. Equally, "faster updates for labs" is mostly a scheduling and pre-filtering problem that BM25-gated, event-driven watchers solve. The agent adds value in the narrow final step of relating a new item to a specific lab's project state under a hard budget.

The publishable contribution is therefore not "Mycelium has an agent". It is three things no catalogued system has: memory provenance that is consent-scoped and keeps no raw text; retraction that propagates as an operation distinct from temporal invalidation; and evaluation that scores lab-grounded utility and contextual-integrity leakage together. All three already exist in Mycelium in synthetic form. The decisive next step is to turn that synthetic evidence into human-judged evidence before claiming more autonomy. That one gap separates Mycelium from every demo it will be reviewed against.
