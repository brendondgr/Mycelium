# Venue Checklists

One file per target venue, committed when the venue is chosen and treated as a
live to-do list — not paperwork assembled in submission week.

Naming: `<venue>-<year>.md`, e.g. `ecir-2027-demo.md`.

Every checklist in this field asks for the same seven things, and all seven are
already manifest fields — see the mapping table in
[`../ARTIFACT_APPENDIX.md`](../ARTIFACT_APPENDIX.md). Filling a checklist should
be transcription, and if it is not, the record has a hole worth finding now.
